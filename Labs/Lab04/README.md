## Lab Summary
In this laboratory work, MySQL and MongoDB container services were set up in a local Ubuntu environment using Docker and Docker Compose. Different approaches for establishing database connections via Python scripts were implemented, including:
1. Hardcoded connection values.
2. Using environment variables (`os.getenv`).
3. Managing `dev`, `test`, and `prod` environments using external configuration files (`credentials.ini` and `configparser`).

All tasks have been successfully verified and documented with screenshots.
